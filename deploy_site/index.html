Theoretical Framework

Mathematical Formulations & Depth Transformations

Mathematical models governing metric depth reconstruction, multi-factor hazard scoring, and spatial safety corridor filtering.

1. KITTI Metric Depth Transform

Intel MiDaS outputs raw relative inverse disparity $d(x,y)$. We project disparity to true physical distance $Z_{\text{metric}}$ (in meters) via our empirical calibration against the KITTI benchmark:

Z_{\text{metric}}(x, y) = \text{clip}\left(\frac{\alpha}{\max(d(x, y), \epsilon)},\; 0.3,\; 8.0\right)

Where $\alpha = 850.0$ and $\epsilon = 80.0$. This maps room-scale disparity directly to calibrated meters.

2. Dynamic Composite Hazard Priority Scoring

To prevent auditory fatigue, candidates are ranked via a linear multi-factor utility function $P(O)$ determining whether speech preemption triggers:

P(O) = S_{\text{motion}} + S_{\text{bearing}} + S_{\text{proximity}} + S_{\text{class}}

Where $S_{\text{motion}} = 60.0$ if $v_{\text{approach}} > 0.35\text{ m/s}$ in path, $S_{\text{bearing}} = 30.0$ for center corridor, and $S_{\text{proximity}} = \max(0, (5.0 - d) \cdot 6)$.

3. Navigational Corridor Height Clamping

Prevents ceiling and ground dilation from skewing forward clearance metrics by isolating the active navigation band:

Y_{\text{active}} = \left[\, 0.22 \times H_{\text{frame}},\; 0.85 \times H_{\text{frame}} \,\right]

Corridor clearance is computed via the 15th-percentile depth metric $\mathcal{P}_{15}(Z_{\text{corridor}})$ to guarantee immunity against specular single-pixel noise.

Multi-Domain System Breakdown

The 8 Specialized Vision Modules

Each module addresses a distinct assistive perception challenge, validated on rigorous academic benchmarks.

MODULE 1

Priority Object Detection

📂 MS COCO 2017 Benchmark

Executes YOLOv8n (Nano) in 10ms with custom clutter suppression. Employs a 'Pass & Announce Next' state machine to track navigation actors sequentially.

MODULE 2

Outdoor Road Navigation

📂 BDD100K Autonomous Driving

Detects roadway actors (cars, buses, bikes, pedestrians, traffic lights) and parses safe sidewalk walking boundaries versus street vehicular hazards.

MODULE 3

Obstacle & Trip Hazard

📂 Mapillary Vistas Dataset

Identifies low-elevation surface threats: curbs, stair steps, potholes, and construction barriers, guarding against sudden foot tripping.

MODULE 4

Place & Scene Recognition

📂 MIT Places365 (ResNet-18)

Classifies 365 scene categories. Features a semantic remapper that accurately resolves student hostel and dorm rooms rather than mistaking them for dressing rooms.

MODULE 5

360° Scene Storytelling

📂 VizWiz-Captions (Assistive Vision)

Combines BLIP vision-language representations, spatial object bounding boxes, metric clearances, and scene classification into vivid conversational descriptions.

MODULE 6

High-Accuracy Reading (OCR)

📂 ICDAR 2015 & COCO-Text

EasyOCR CRAFT + Gen2 with 1.5x upscaling, CLAHE contrast boost, and fuzzy brand dictionary mapping. Successfully reads curved, reflective hardware like 'Acer Mouse'.

MODULE 7

GPS Wayfinding & POI

📂 OpenStreetMap (OSM)

Real-time haversine distance computation, directional compass tape, and landmark proximity alerts for pharmacies, bus transit, and pedestrian crosswalks.

MODULE 8

Calibrated Metric Depth Radar

📂 KITTI Vision Benchmark

Intel MiDaS v2.1 Small calibrated to metric meters ($0.3\text{m} - 8.0\text{m}$). Features Left/Center/Right tri-sector proximity badges and instant reticle target distance.
